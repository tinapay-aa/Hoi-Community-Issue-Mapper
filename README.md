# Hoi – Community Issue Mapper

## Description

Hoi – Community Issue Mapper is a web-based community issue reporting and mapping system designed to help individuals report, monitor, and manage problems within their communities. It provides a centralized platform where users can submit community concerns, identify issue locations, and help promote awareness of local problems.

The system aims to improve community participation and make it easier to document, visualize, and monitor reported concerns through an organized platform.

## Features

- *Community Issue Reporting* – Allow users to submit and document issues within their communities.
- *Issue Management* – Create, view, update, and delete reported community issues.
- *Issue Categorization* – Organize reported concerns according to their respective categories.
- *Location Mapping* – Associate reported issues with specific geographical locations.
- *Community Issue Monitoring* – View and monitor submitted community concerns.
- *User Authentication* – Provide account registration and login functionality.
- *Image Uploads* – Support uploading images as supporting evidence for reported issues.
- *Administrative Management* – Manage community issue records and system information.

## Technology Stack

- *Backend:* Python, Django
- *Frontend:* HTML, CSS, JavaScript
- *Database:* SQLite
- *Authentication:* Django Allauth
- *Image Processing:* Pillow
- *HTTP Requests:* Requests
- *Environment Configuration:* Python Dotenv
- *Development Tools:* Visual Studio Code, Git, GitHub
